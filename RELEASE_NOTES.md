# VRKA Android 5.0.1

## What's New

- Fixed in-app update detection and exact APK selection.
- Improved verification before handing downloaded updates to Android's installer.

## VRKA Android 5.0

- Redesigned the interface with Liquid Glass navigation and swipe paging.
- Added configurable concurrent downloads and Android Share Sheet support.
- Improved Browser Fallback discovery and reliability.
- Added custom yt-dlp command templates and optional H.264 Compatibility Mode.
- Improved subtitles, download history, metadata, and job persistence.
- Updated GeckoView and browser components, with security and reliability improvements.

## Known Limitations

- Browser Fallback downloads do not include subtitles.
