VRKA Android is a native media downloader and passive web stream discovery application for Android devices.

Built with Jetpack Compose, Kotlin Coroutines, yt-dlp and FFmpeg, VRKA performs media transfers locally. When an eligible direct extraction fails, its embedded Mozilla GeckoView browser can discover media candidates; VRKA hands a selected candidate to the same yt-dlp transfer path.

Key Features:
- Direct media extraction and downloads using yt-dlp, with optional local FFmpeg processing.
- Full interface localization supporting 14 languages (Arabic, Bengali, Simplified Chinese, English, French, German, Gujarati, Hindi, Kannada, Portuguese Brazil, Portuguese Portugal, Spanish, Tamil, Telugu) and System Default.
- Preflight download size estimation for direct downloads and Android Share Sheet.
- Quality selection, actual-resolution tracking, video/audio formats, subtitle download and embedding on the normal yt-dlp path, and optional H.264 conversion.
- Persistent job queue and history with optional 2–4 job concurrency; sequential mode remains the default.
- Android share-sheet URL intake and sharing of published output files.
- Custom Referer and Origin fields with validation and CRLF injection protection.
- Sensitive-data redaction for authorization tokens, cookies, and secret headers in diagnostics and history.
- GeckoView Browser Fallback for eligible anti-bot or client-side player failures. Site compatibility varies.
- A VRKA media-detector WebExtension discovers and ranks stream candidates; uBlock Origin filters browser requests.
- Browser Fallback transfers use yt-dlp. FFmpeg handles local processing; VRKA does not use an app-owned native HLS/DASH transfer engine.
- Application updates require canonical stable release tags and exact APK names, validate each HTTPS redirect, and verify package, version, version code, and signing certificate before installation.
- Local on-device processing with no application telemetry or cloud tracking.
- Component updates for yt-dlp and uBlock Origin are verified before installation, with support for custom yt-dlp runtimes.
