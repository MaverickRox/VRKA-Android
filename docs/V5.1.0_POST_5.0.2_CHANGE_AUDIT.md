## 4. F-Droid Merge Request !49780 Analysis

**GitLab Merge Request Reference**: [`https://gitlab.com/fdroid/fdroiddata/-/merge_requests/49780`](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/49780)

### 4.1 Categorization Matrix

#### Category A: Universal Privacy & Performance Improvements (Preserved Across All Distributions)
- **WebExtension Telemetry Disabling**: Disabling embedded add-on telemetry (uBlock Origin, Puemos) improves user privacy unconditionally, regardless of distribution channel.
- **Static XPI Manifest Inspection**: Reading local extension manifest files directly rather than spinning up the GeckoView engine accelerates cold application boot times.
- **Safe Browsing Fallback**: Retained domain checking protects users against unsafe interactive web sessions.

#### Category B: F-Droid Policy Compliance (Distribution-Specific)
- **Opt-in Update Checking**: F-Droid policies flag applications with built-in binary updaters with the `UpstreamNonFree` anti-feature unless automatic checks are opt-in (`autoCheckAppUpdates = false`, `autoCheckComponentUpdates = false`).
- **GeckoView Source Build Resolution**: F-Droid builds GeckoView from source (`srclib: mozilla`) and resolves artifacts via `mavenLocal()`. Removing Mozilla's remote Maven URL prevents network calls during the build.

#### Category C: F-Droid App Store Presentation & Metadata
- **Fastlane Directory (`fastlane/metadata/android/en-US/`)**: Phone screenshots, short/full descriptions, feature graphic, and icon provide standard packaging for F-Droid and third-party stores.

#### Category D: Documentation & Reproducibility Alignment
- **Build Environment & Reproducibility**: Documented SDK/NDK requirements, environment variable configurations, and checksum matching instructions (`REPRODUCIBLE_BUILDS.md`).

#### Category E: Distribution-Specific Divergences
- Standard GitHub release APKs utilize prebuilt Mozilla Maven dependencies for build stability without requiring a 60GB GeckoView source tree. VRKA Android v5.1.0 maintains standard build ergonomics while respecting F-Droid source guidelines.
